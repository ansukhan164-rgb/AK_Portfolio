## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/ansukhan164-rgb/AK_Portfolio.git
```

### Navigate to Project Folder

```bash
cd AK_Portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

or

```bash
npm start
```
